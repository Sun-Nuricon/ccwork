2. State Flow — 노트 저장 시나리오

sequenceDiagram
  actor User as 사용자
  participant Editor as NoteEditor
  participant Ctx as NotesContext
  participant API as api/notes.ts
  participant Server as json-server (3001)

  User->>Editor: 제목/내용 입력 + 저장 클릭
  Editor->>Editor: handleSave() — 검증
  alt 제목 비어있음
    Editor-->>User: console.error
  else 검증 통과
    Editor->>Ctx: createNote(title, content)
    Ctx->>API: createNote({title, content})
    API->>Server: POST /notes (+ createdAt/updatedAt)
    Server-->>API: 새 Note (id 포함)
    API-->>Ctx: Note
    Ctx->>Ctx: setNotes(prev => [...prev, newNote])
    Ctx-->>Editor: 리렌더 (notes 변경)
    Editor->>Editor: onDone() — 편집 모드 종료
  end

3. State Flow — 초기 로딩

sequenceDiagram
  participant App as App.tsx
  participant Provider as NotesProvider
  participant API as api/notes.ts
  participant Server as json-server

  App->>Provider: 마운트
  Provider->>Provider: useEffect (mount)
  Provider->>API: fetchNotes()
  API->>Server: GET /notes
  alt 성공
    Server-->>API: Note[]
    API-->>Provider: Note[]
    Provider->>Provider: setNotes + setLoading(false)
  else 실패
    Server-->>API: error
    API-->>Provider: throw Error
    Provider->>Provider: setError + setLoading(false)
  end
