## 개요

매칭되는 노트가 0개일 때 "검색 결과가 없습니다"를 보여줘 사용자가 빈 화면에 당황하지
않게 한다. 원래 노트가 없는 상태("노트가 없습니다")와는 구분되는 별도 메시지.

기준 문서: `docs/features/search/prd.md`

## 범위

- `NoteList`에서 필터 결과가 0개이고 `query.trim()`이 비어있지 않을 때, 한국어 안내
  문구를 early return으로 렌더(기존 빈/로딩/에러 early return 패턴 따름).
- 원래 노트가 0개인 경우(`notes.length === 0`)의 기존 "노트가 없습니다"는 그대로 유지.
- 결과 없음일 때 카운트 헤더("노트 N개")는 표시하지 않고 메시지로 대체.

## Acceptance Criteria

- [ ] Given 노트가 있지만, When 어느 노트와도 매칭되지 않는 키워드를 입력하면, Then "검색 결과가 없습니다"가 표시된다.
- [ ] Given "검색 결과가 없습니다"가 보이는 상태에서, When 검색창을 비우면, Then 전체 노트 목록으로 돌아간다.
- [ ] Given 노트가 1개 이상 있고 검색 결과가 0개일 때, When 메시지를 보면, Then "검색 결과가 없습니다"이며 기존 "노트가 없습니다"와는 다른 문구다.
- [ ] Given 원래 노트가 0개인 상태에서, When 검색창이 비어 있으면, Then 기존 "노트가 없습니다" 메시지가 보인다(검색 결과 없음 메시지가 아님).

## 의존성

이슈 1 (검색 input·필터링이 존재해야 함). 역방향 의존 없음.
