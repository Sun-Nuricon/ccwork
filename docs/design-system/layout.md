# 레이아웃 (Layout)

> [디자인 시스템 README](./README.md)의 하위 문서. 스페이싱·그리드·반응형·깊이·형태.
>
> **값의 권위는 [`tokens.css`](./tokens.css)** 다. 아래 표는 가독용 미러이며,
> 충돌 시 tokens.css가 이긴다.

## 1. 스페이싱 시스템

- **베이스 단위**: 4px (2 / 6 / 10 중간값 포함). 1996 레이아웃은 설계된 스케일이 아니라
  HTML 테이블 셀 패딩(`cellpadding="4"` `cellspacing="0"`)에서 비롯됐다.

| 토큰          | 값   |     | 토큰                 | 값   |
| ------------- | ---- | --- | -------------------- | ---- |
| `spacing.xxs` | 2px  |     | `spacing.lg`         | 16px |
| `spacing.xs`  | 4px  |     | `spacing.xl`         | 20px |
| `spacing.s`   | 6px  |     | `spacing.xxl`        | 24px |
| `spacing.sm`  | 8px  |     | `spacing.section-sm` | 32px |
| `spacing.m`   | 10px |     | `spacing.section`    | 40px |
| `spacing.md`  | 12px |     | `spacing.section-lg` | 48px |

- **카드 내부 패딩**: 리본카드 본문은 세로 `md`(12px) / 가로 `lg`(16px).
- **섹션 세로 리듬**: 제품 리본 스택 사이 `section`(40px); eyebrow 색 블록과 첫
  리본카드 사이 `section-sm`(32px).

## 2. 그리드 & 컨테이너

- **고정폭 테이블 레이아웃 ~760px** — 800×600 모니터(+스크롤바 여백)를 노린 1996 표준.
- **2열 외곽 구조**: 좌측 레일(~28%)은 홈 아이콘 링크 그리드 + 빨강 CTA 패널, 우측
  컬럼(~72%)은 제품 리본 스택.
- 현대적 의미의 그리드 시스템 없음 — 섹션마다 자체 `<table>` + 하드코딩 컬럼 폭.

### Whitespace 철학

현대 기준으로는 빽빽하다. 편집적 여백보다 카탈로그 밀도가 이긴다 — 검정 프레임 안의 모든
픽셀이 일한다. 숨통은 **각 리본카드 내부**에서 튼다: 흰 타이틀바 + 틴트 바디 + 사진 노치가
전체 페이지를 키우지 않고도 내부 호흡을 만든다.

## 3. 반응형

### 브레이크포인트

| 이름          | 폭      | 주요 변화                                                       |
| ------------- | ------- | --------------------------------------------------------------- |
| 시대 기본     | 800×600 | 760px 고정 레이아웃                                             |
| 모던 데스크톱 | 1280px+ | 중앙 정렬 + 넉넉한 좌우 거터("화면 한가운데 잡지 펼침")         |
| 태블릿        | 768px   | 검정 프레임 4px로 압축, 리본카드 풀폭 스택                      |
| 모바일        | <480px  | 프레임 2px, 2열 → 1열 붕괴, 좌측 아이콘 그리드가 제품 스택 위로 |

### 터치 타깃

1996년엔 터치 개념이 없었다(마우스 전용 가정). **현대 재현은 모바일에서 아이콘 내비
타깃을 최소 44×44px로 넓혀야 한다** (원본 아이콘은 ~24×24 + 하단 8px 라벨로 현대
가이드라인 미달).

### Collapsing 전략

- ≤768px: 홈 좌측 아이콘 링크 그리드(Online Store/Service/Why Dell?/Government/
  Worldwide/Order Status/Company Info/U.S. Careers)가 2×4 → 1열 스택.
- 리본카드 우측 사진 노치 → 모바일에선 상단 정렬 풀폭 이미지.
- 상단 배너 태그라인은 한 타입 티어 축소, 전화번호는 BUY-a-DELL 스티커 아래로 줄바꿈.
- 푸터 아이콘 내비는 전 폭에서 4-up 유지(아이콘이 충분히 작음).

### 이미지 동작

제품 사진은 손으로 베벨 섀도를 입힌 비트맵 GIF로, 고정 픽셀 폭(보통 80~120px)으로
제작됐다. 우측 노치 효과는 테이블 셀 음수 간격으로 구현. **현대 재현은 베벨 섀도(시그니처)는
유지하되 고해상도에서 또렷하게 `filter: drop-shadow(2px 2px 0 #000)`로 재현한다.**

## 4. Elevation & Depth (깊이)

| 레벨         | 처리                               | 용도                            |
| ------------ | ---------------------------------- | ------------------------------- |
| 0 — Flush    | 섀도·보더 없음                     | 본문, 저작권 행, 푸터 밴드 배경 |
| 1 — Hairline | `1px solid frame-ink`              | 리본카드 외곽, 테이블 셀 구분선 |
| 2 — Frame    | `8px solid frame-ink`              | 전체 뷰포트 페이지 프레임       |
| 3 — Bevel    | 하드엣지 1px 하이라이트 + 1px 섀도 | GIF 스티커, 제품 사진           |

**소프트 섀도는 존재하지 않는다.** 모든 깊이 단서는 하드 1px 보더 또는 GIF 안에 손으로
칠한 베벨이다. 깊이 어휘 전체를 베벨과 프레임이 짊어진다 — 페이지 프레임이 가장 강한 깊이
단서("이건 연속 캔버스가 아니라 담긴 문서다"), 스티커 베벨은 압정으로 꽂은 듯 떠 보이게,
제품 사진은 GIF에 구워진 자체 베벨+드롭섀도.

## 5. Shapes (형태)

| 토큰           | 값     | 용도                                                            |
| -------------- | ------ | --------------------------------------------------------------- |
| `rounded.none` | 0px    | 보편 기본값 — 버튼·카드·인풋·배너·프레임·리본 바디·eyebrow 블록 |
| `rounded.full` | 9999px | 원형 award 씰(PC Magazine), HOME 아이콘의 둥근 "h" 스티커       |

라디우스 모드는 사실상 **둘뿐** — 사각(전부)과 원형(장식 씰). 4/8/12px 미세 단계는
post-Bootstrap 웹의 어휘이며 여기엔 없다.

### Photography Geometry

제품 사진은 자체 내부 베벨 "모니터" 프레이밍을 가진 직사각 GIF — 네이티브 픽셀
치수로만 두고 절대 스케일하지 않는다. 종횡비는 4:3(시대의 CRT 형태) 근처. 아바타는 없다.

## Tailwind 매핑

| 추상 토큰                | Tailwind                                                                       |
| ------------------------ | ------------------------------------------------------------------------------ |
| `spacing.*` (4px 베이스) | 기본 spacing 스케일(`p-1`=4px, `p-3`=12px, `p-4`=16px …) 또는 `p-[Npx]` 임의값 |
| `rounded.none`           | `rounded-none`                                                                 |
| `rounded.full`           | `rounded-full`                                                                 |
| Elevation 2 — Frame      | `border-8 border-frame-ink`                                                    |
| Elevation 1 — Hairline   | `border border-frame-ink`                                                      |
| Elevation 3 — Bevel      | `drop-shadow-[2px_2px_0_#000]` (소프트 섀도 금지)                              |

> **현재 `@theme`의 `--radius: 0.75rem`(12px)는 교체 대상이다.** Dell 1996 기준의
> 기본 라디우스는 0이므로, 컴포넌트는 `rounded-none`을 명시하거나 `--radius`를 0으로 둔다.

## Do / Don't

### ✅ Do

- **검정 페이지 프레임(8px)을 모든 페이지에 유지**하고, 좁은 화면에서만 4→2px로 압축.
- **기본 라디우스 0** — 사각이 보편, 둥근 건 award 씰만.
- 깊이는 하드 1px 보더 또는 하드엣지 베벨로만 표현한다.
- 카탈로그 밀도를 유지하되 호흡은 카드 내부(타이틀바/바디/노치)에서 만든다.

### ❌ Don't

- **모서리를 둥글리지 않는다**(award 씰 제외).
- **소프트 드롭섀도·Material식 elevation·분위기용 그라데이션을 넣지 않는다.**
- 페이지 프레임을 완전히 제거하지 않는다(모바일 축소는 허용).
- 제품 사진을 스케일·왜곡하거나 `clip-path`로 자르지 않는다.
