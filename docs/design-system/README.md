# 디자인 시스템 — Dell 1996 카탈로그 스타일

> 출처: `getdesign.md`로 제공된 "Dell December 1996 home page" 디자인 시스템 스펙을
> 프로젝트 정식 문서로 정착시킨 것. **이 문서는 앞으로 모든 스타일 작업의 단일 참조
> 기준(source of truth)이다.** 새 컴포넌트 작성·스타일 변경 시 먼저 이 폴더를 읽는다.

## 한 줄 정체성

**1996 카탈로그 시대 엔터프라이즈 웹** — CSS 보급 이전, HTML 테이블로 레이아웃을 짜고
브라우저 기본 폰트 스택으로 타입을 세우던 시절의 디자인. 화면을 "액자에 넣은 인쇄물"처럼
다룬다: 검정 액자 프레임 안에 플랫 컬러블록 "리본카드"를 쌓고, 손으로 오려낸 GIF 스티커를
얹는다. 그라데이션·소프트 섀도·둥근 모서리·웹폰트는 **시대착오(anachronism)** 다.

## Key Characteristics (핵심 특징 6)

1. **검정 페이지 프레임** — 모든 페이지가 약 8px 두께의 검정(`--color-frame-ink`) 외곽
   테두리 안에 들어간다. 브라우저 창을 인쇄 사진의 액자처럼 취급한다.
2. **리본카드 틴트** — 제품군마다 전용 카탈로그 색(sage/salmon/periwinkle/sky …)으로
   본문 블록을 칠한다. 그라데이션·섀도·투명도 없음, 오직 플랫 채움.
3. **청키 디스플레이 타이포** — 섹션 제목은 Arial Black 36px / weight 900. 본문은
   Times Roman 14px. UI는 sans, 본문은 serif — 현대와 정반대.
4. **GIF 스티커 오버레이** — 노란 "BUY a DELL" 탭, 비스듬한 "NEW!" 버스트, 둥근 빨강
   PC Magazine Readers' Choice 씰이 레이아웃 위에 핀으로 꽂힌 듯 얹힌다.
5. **Dell red 제한 사용** — `--color-primary`(Dell red)는 단 두 곳, 홈 CTA 패널과
   우상단 전화번호에만 쓴다. 절대 장식용으로 쓰지 않는다.
6. **클래식 블루 링크** — 인라인 앵커는 Netscape 3.x 기본 링크색(`#0000ee`)에 밑줄.

## Do's & Don'ts (총칙)

각 하위 문서에 항목별 상세 Do/Don't가 있다. 여기서는 디자인 전체를 관통하는 원칙만.

### ✅ Do

- **검정 페이지 프레임을 모든 페이지에 유지한다.** 이 브랜드의 가장 식별성 높은 컨테이너
  크롬이다. 모바일에서 ~4px로 줄이는 건 허용, 제거는 불가.
- **Dell red는 CTA 패널과 전화번호에만 쓴다.** 그 외 모든 사용은 긴급 신호를 희석한다.
- **8색 틴트를 패밀리로 쓴다.** 제품군당 1색을 정하고 그 라인 전체에서 일관 유지.
- **모든 디스플레이 헤드라인은 Arial Black 36 / weight 900.** 플랫 컬러 위 극단적
  굵기가 이 브랜드의 타이포 레지스터다.
- **본문은 Times Roman 14 유지.** 모던 sans로 바꾸면 카탈로그 느낌이 통째로 사라진다.
- **모든 CTA·버튼은 radius 0(`rounded-none`).** 둥근 버튼은 시대를 배신한다.
- **스티커·제품 사진엔 하드엣지 베벨/GIF 섀도를 쓴다.** 소프트 CSS 섀도로 대체 금지.

### ❌ Don't

- **8색 틴트 + Dell red + Dell yellow + 클래식 링크 블루 밖의 색을 도입하지 않는다.**
  팔레트는 설계상 폐쇄형이다.
- **어떤 모서리도 둥글리지 않는다.** `rounded-none`이 보편 기본값, 둥근 건 award 씰만.
- **Times Roman 본문을 Arial/Helvetica/Inter/웹폰트로 바꾸지 않는다.** serif 본문이
  이 시대의 시그니처다.
- **소프트 드롭섀도·분위기용 그라데이션을 넣지 않는다.** 하드 보더 + 플랫 채움만.
- **제품 사진을 `border-radius`·`clip-path`로 자르거나 "끼워넣지" 않는다.** 리본카드
  우측 노치가 프레이밍이고, 사진 자체는 하드 직사각형으로 둔다.
- **CTA red 패널을 한 페이지에 2개 두지 않는다.** red는 단일 집중 포인트여야 한다.
- **상단 배너의 전화번호를 제거하지 않는다.** 1996년 웹은 전화 주문을 유도하는
  브로슈어였다 — 전화번호가 곧 내비게이션이다.

## 현재 코드와의 관계 (중요)

현재 앱 테마(`src/index.css`의 `@theme`)는 Pretendard/Boogaloo 폰트 + 라이트 그레이
배경 + shadcn식 네이밍으로, **이 Dell 1996 기준과 정반대다.** 이 문서는 "앞으로 지향할
디자인 기준"을 정의하며, 실제 `index.css` 토큰 교체는 **별도 구현 작업**이다. 각 매핑표는
현재 테마와 충돌하는 토큰을 **"교체 대상"** 으로 표기한다.
